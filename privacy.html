プライバシーポリシー

最終更新: 2026-11-19

対象

Sapphire notch（以下「本アプリ」）は、作者本人が自分の Mac で使う個人用ツールです。第三者への配布は行っていません。

Google アカウントで取得する情報

本アプリは YouTube Data API（スコープ youtube.readonly）を使い、ログインしたユーザー本人の「高く評価した動画」「プレイリスト」「登録チャンネル」の一覧（動画タイトル・サムネイル・ID）を取得します。書き込み・投稿・変更は一切行いません。

保存場所と期間

取得した一覧は、本アプリを動かしている Mac の中（アプリのキャッシュファイル）にのみ保存されます。ログインのためのトークンは macOS のキーチェーンに保存されます。いずれも外部サーバーへ送信しません。ユーザーがアプリ内で「Sign out」を選ぶと、トークンとキャッシュは削除され、Google 側のトークンも失効させます。

第三者への提供

取得した情報を第三者に提供・販売・共有することはありません。Google API から得たデータの利用は、Google API サービスのユーザーデータに関するポリシー（限定使用の要件を含む）に従います。

アクセスの取り消し

いつでも Google アカウントの「サードパーティ製のアプリとサービス」 から本アプリのアクセスを取り消せます。

連絡先

本ポリシーについての問い合わせは、Google Cloud の OAuth 同意画面に登録したサポートメールまでお願いします。

Privacy Policy

Sapphire notch is a personal macOS utility used only by its author; it is not distributed to others.

Data accessed: with the youtube.readonly scope of the YouTube Data API, the app reads the signed-in user's own liked videos, playlists and subscriptions (titles, thumbnails, IDs). It never writes, posts or modifies anything.

Storage: the fetched lists are cached only on the Mac running the app; the sign-in token is stored in the macOS Keychain. Nothing is sent to any server other than Google's API. Choosing "Sign out" in the app deletes the token and cache and revokes the token with Google.

Sharing: the data is never shared with or sold to third parties. Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access: you can revoke the app's access at any time from your Google Account third-party access page.
